## 预先规定的判断方式

- H1：逐次记录是否召回 AGENTS 中 full-criterion 的条件规则；同时保存分数、路径、
  完整片段。没有召回就是该查询的检索失败；不能将改写命中推导成原查询稳定。
- E3：必须分别描述 stdio 的 ReloadGraph 提前返回与 CheckReload 进入 runtime，
  以及直接调用 GraphRuntime::query 的内部处理；混写为同一 stdio 提前返回判 fail。
- B6：同事务持久化与合并报告须正确；不得把 hydrate_diagnostics 当 scanner 诊断读取。
  片段未给出精确读取 API 时可明确未知，不要求猜中函数名。遗漏已可回答的核心机制判 partial，
  编造读取 API 或把 hydrate 完整性诊断当 scanner 诊断判 fail。
- 每条完整回答都检查附加断言；只修复目标错误但引入其他错误不能记 pass。
  每个处理、每道题分别列 pass/partial/fail，不自动判分、不以脚本退出零当通过。
  3 次全对只说明本轮观测，不能证明稳定率或全题集改进。
